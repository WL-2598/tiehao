    常见问题

    图片会上传吗？

    不会。裁切、水印、压缩和打包都在浏览器本地完成；页面本身也不依赖外部字体、脚本或图片。

    这些尺寸是平台官方规定吗？

    不是。它们是常用工作画布，方便统一一组图的构图；平台规则可能变化，发布前请以平台最新要求为准。

    支持哪些格式？

    输入支持 JPEG、PNG、WebP。暂不支持 HEIC、SVG、GIF 动图或 RAW；请先导出为上述格式。

    离线版怎么用？

    购买后下载一个 HTML 文件，双击用浏览器打开即可。无需安装，也无需联网。建议 Chrome / Edge / Firefox / Safari 的较新版本。

    可以商用吗？

    工具本身可用于商业出图。输出图片的权利取决于你输入的原图、字体和品牌素材；请确保你拥有相应权利。

    开源许可如何处理？

    本产品使用 MIT 许可的 browser-image-compression 与 JSZip，并在页面底部和离线包中保留许可声明。产品自身代码与上游开源项目分开标注。
