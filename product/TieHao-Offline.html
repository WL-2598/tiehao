功能

批量出图需要的，都在这里

从裁切构图到体积压缩，全部在浏览器里完成。没有套路，没有水印，没有账号。

常用画布预设

3:4 竖版图文、1:1 商品方图、16:9 横版封面、9:16 视频画面，也支持保持原尺寸与自定义尺寸。

留白或裁切

完整保留构图就留白并自定义底色；要铺满画面就居中裁切。批量应用，每张都一致。

品牌文字水印

五个位置、平铺满图、大小透明度、字体与描边都能调。调好存成预设，下次一键载入。

目标体积压缩

按目标 KB 收敛 JPEG / WebP 输出，先降质量、必要时再缩画布，尽量保住清晰度。

ZIP + CSV 清单

一键打包全部成品，附带 manifest.csv（原文件、画布、格式、体积变化），方便对账与归档。

品牌预设

把常用的画布、水印、压缩组合存进浏览器，支持 JSON 导入导出，换电脑也能带走。

    常见问题

    你可能想问

    图片会上传吗？

    不会。裁切、水印、压缩和打包全部在你的浏览器里完成，页面也不依赖外部字体、脚本或图片。断网后打开在线版生成的页面同样无法回传任何数据——因为数据从来没有离开过你的设备。

    支持哪些格式？

    输入支持 JPEG、PNG、WebP。输出可选 JPEG、WebP、PNG。暂不支持 HEIC、SVG、GIF 动图或 RAW，请先在系统相册或修图软件里导出为上述格式。

    这些尺寸是平台官方规定吗？

    不是。它们是常见的工作画布，方便统一一组图的构图。各平台规则可能变化，发布前请以平台最新要求为准。

    目标大小压不到怎么办？

    工具会先降低压缩质量，仍超标时再按比例缩小画布，并尽量保住清晰度。如果目标 KB 设得比原图还大，或图片本身极小，可能无法精确命中——此时会输出该质量下最小的结果，并在清单里标明实际大小。

    水印可以铺满整张图吗？

    可以。勾选“平铺”后，水印会按倾斜角度重复铺满画面，适合防盗图；日常使用建议用角落单条水印，更干净。

    离线版怎么用？

    购买后下载一个 HTML 文件，双击用浏览器打开即可，无需安装、无需联网。建议 Chrome / Edge / Firefox / Safari 的较新版本。

    可以商用吗？

    工具本身可用于商业出图。输出图片的权利取决于你输入的原图、字体与品牌素材，请确保你拥有相应权利。

    开源许可如何处理？

    打包使用了 MIT 许可的 JSZip（页面底部与离线包内保留许可声明）。产品自身代码与上游开源组件分开标注。
