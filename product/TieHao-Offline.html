功能

批量出图需要的，都在这里

从裁切构图到体积压缩，全部在浏览器里完成。没有套路，没有水印，没有账号。

一图多版，一次导出

勾选多个平台目标，同一张原图按 31 种规格分别输出。不用再为每个平台手动改一遍尺寸——这是最费时间的那一步。

文案直接排进图里

标题、卖点、角标、价签、页脚，6 种版式自动排版并处理文字遮挡与对比度。不用再开设计软件拼图。

安全区预览

每个平台都会用 UI 压住画面边缘（抖音右侧、微博底部…）。按目标平台画出安全区，主体不会被裁掉。

品牌标识与白边裁剪

上传一次 Logo，批量贴到每张图的指定角落；商品图的白底留白自动裁掉，构图立刻紧凑。

电商上架合规

淘宝第 5 张白底图必须纯白无字、京东主图 ≤1MB、详情页宽 750 且单张 ≤1500 高。选上目标就按规范出图，长图自动切片，不会把一行字切成两半。

目标体积 + 焦点裁切

按目标 KB 收敛 JPEG / WebP；铺满裁切时可拖动焦点，决定保留构图里的哪一块。

按平台分目录打包

ZIP 内按平台建目录，附 manifest.csv（原文件→输出文件、画布、体积变化），交付与归档都能直接对账。

    常见问题

    你可能想问

    在线版和离线版到底差在哪？

    在线版能完整跑通裁切、水印、目标体积压缩和 ZIP 导出，只是每批 3 张、只有 4 个常用平台。离线版的核心不是「解锁」，而是「一图多版」：一张原图一次导出 31 种平台规格，再加上文案排版、品牌 Logo、白边裁剪和焦点裁切。这些能力解决的是同一件事——别再为每个平台手工改一遍尺寸。

    图片会上传吗？

    不会。裁切、水印、压缩、排版和打包全部在你的浏览器里完成，页面不依赖任何外部字体、脚本或图片。断网后打开离线版同样无法回传任何数据——因为数据从来没有离开过你的设备。

    这些尺寸是平台官方规定吗？

    不是。它们是各平台常见的工作画布与交付规格，并标注了会压住画面的 UI 区域（安全区）。平台规则可能变化，发布前请以平台最新要求为准。

    文案排版的字体会不会不一致？

    水印与文案使用系统字体渲染。同一台电脑上批量出图完全一致；换到另一台电脑（比如把预设导给同事）字体可能略有差别。这是「完全离线、不加载在线字体」的代价。

    目标大小压不到怎么办？

    先降压缩质量，仍超标时再按比例缩小画布。如果目标设得比原图还小很多，可能无法精确命中——此时输出该设置下最小的结果，并在队列与 manifest.csv 里标明「未达目标」，不会假装成功。

    白边裁剪会不会裁掉主体？

    它只裁掉与「识别底色」接近的外圈像素，并且会在四周保留少量余量。识别底色可调，建议先用一张图确认容差再批量跑。

    离线版怎么用？

    购买后下载一个 HTML 文件，双击用浏览器打开即可，无需安装、无需联网。建议 Chrome / Edge / Firefox / Safari 的较新版本。

    可以商用吗？

    工具本身可用于商业出图。输出图片的权利取决于你输入的原图、字体与品牌素材，请确保你拥有相应权利。

    开源许可如何处理？

    打包使用了 MIT 许可的 JSZip（页面底部与离线包内保留许可声明）。产品自身代码 MIT，与上游开源组件分开标注。
